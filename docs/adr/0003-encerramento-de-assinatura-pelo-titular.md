# Encerramento de assinatura pelo titular

O titular pode encerrar uma assinatura de mensagens pelo painel de conexões. Como o aplicativo pode renovar automaticamente, o WaPilot recusa novos pedidos para a mesma assinatura com a autorização original, mesmo depois de remover os dados operacionais da assinatura. Uma nova autorização concedida pelo titular permite um novo cadastro com o mesmo destino e filtro.
